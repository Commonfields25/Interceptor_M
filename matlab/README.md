# MATLAB Technical Verification Suite
This directory contains the scripts used to verify the Interceptor_M against its engineering constraints.

## Scripts
1. `interceptor_performance.m`: Aerodynamic and turn performance calculations.
2. `feasibility_study.m`: Mass margin and structural load analysis for the DD-line.
3. `constraint_test_runner.m`: Master runner script for automated validation.

## Usage
Run `constraint_test_runner.m` in MATLAB or Octave to perform a full technical audit of the project baseline.
