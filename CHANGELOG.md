## [3.0.0] — 2026-07-10

### 🔖 Highlights
This release marks the transition from Phase 1/2 to **Phase 3 (High-Fidelity Engineering)**.
Key deliverables from PRs #272 and #273 are included: complete G3 preliminary design with
PyCad L3 standards, production drawings, BOM consolidation, and full CI automation.

### 🚀 Features
- **G3 High-Fidelity Preliminary Design**: Complete PyCad-based parametric CAD with
  L3 standards, assembly drawings, and manufacturing specs for all critical parts
  (BRK-001, ACT-001, NCR-001).
- **CI/CD Pipeline**: Resolved all GitHub Actions failures; Python CI, Security,
  ISO-Compliance, and Documentation workflows now run cleanly.
- **Governance Reinforcement**: Namespace isolation, IAMD enforcer, auto-approval policy,
  and bot guidelines fully operational.
- **Bot-Driven Issue Resolution**: Automated closing of resolved documentation and
  cleanup issues (#259–#266).
- **Product Family Expansion**: F1 high-speed quad concept added alongside DD/DI/DC lines.

### 🛠️ Changes
- **Version bump to 3.0.0** across all config files:
  `pyproject.toml`, `project.json`, `PARAMETERS.json`, `params_D*.json`,
  `PRODUCT-FAMILY.md`, `STATUS-REPORT.md`.
- BOM Master baseline locked at v3.0.0.
- MILESTONE_PLAN updated with G3/G4 gate review targets.

### 🐛 Fixes
- Resolved degenerate STL meshes (BRK-001 pocket cuts).
- Fixed missing parts in CAD library (`AV-MNT-01`, `BAT-CASE-01`, `PAYLOAD-01`).
- Corrected GitHub Actions runner failures across all workflow files.
- Patched requirements.txt and added `.mlc_config.json`.

### 📦 Dependencies
- No new external dependencies added in this release.

### 🔒 Security
- Secrets scanner and Python security jobs hardened.

### 🏗️ Infrastructure
- Supabase integration guide and Linear↔GitHub↔Supabase sync pipeline operational.
- ICAD engine (`icad/`) with standards and CLI for parametric CAD generation.
- Parametric BOM sync (`scripts/bom_param_sync.py`) operational.
