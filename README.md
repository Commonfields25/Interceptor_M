# 🛸 Interceptor_M

**Intercepteur de drones par essaim (Swarm Drone Interceptor System)**

## 📌 Project Overview
Project focused on developing a modular drone platform, with a primary emphasis on a **Defense Swarm Interceptor** launched via compressed air.

## 🛠 Tech Stack (Agent-Friendly)
- **CAD:** Fusion 360, SolidWorks, Inventor
- **Simulation:** Ansys, OpenFOAM, Isaac Gym
- **Firmware:** PX4 / ArduPilot
- **AI/ML:** PyTorch, TensorRT

## 🤖 Team Structure
- **Management:** Agent Manager, AC Agent
- **Designers:** D1 (Civil), D2 (Industrial), D3 (Defense)
- **Engineers:** E1 (Systems), E2 (Propulsion), E3 (Electronics)
