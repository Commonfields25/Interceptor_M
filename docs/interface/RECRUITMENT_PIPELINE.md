## 1. Pipeline de Sélection

```
Candidature reçue
    ↓
[SCREENING] — Vérification CV / critères minimums
    ↓
[ENTRETIEN TECHNIQUE] — Évalué par Lead Engineer + 2 reviewers
    ↓
[ENTRETIEN DG] — Fit culture / motivation / budget
    ↓
[OFFRE] — Rédigée par RH, validée DG
    ↓
[ONBOARDING] — Planifié dès validation offre
```

## 2. Scoring Technique — Critères Avant 1er Entretien

| Critère | Pondération | Échelle |
|---------|------------|--------|
| Expérience CAO / conception aéronautique | 30% | 1-5 |
| Maîtrise procédés avancés (DMLS/CNC) | 25% | 1-5 |
| Compréhension cycle de vie / TRL | 20% | 1-5 |
| Soft skills / communication | 15% | 1-5 |
| Motivation projet défense | 10% | 1-5 |

**Seuil de passage :** ≥ 3.5/5 global ET ≥ 3/5 sur chaque critère ≥ 20%
